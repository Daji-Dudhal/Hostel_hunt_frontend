# 🏠 Hostel Hunt

A modern Full Stack Hostel Booking and Management System built using **React.js**, **Spring Boot**, and **MySQL**.

## ✨ Features

- 👨‍🎓 Student Login & Signup
- 🏠 Hostel Owner Login & Signup
- 🔑 Admin Login
- ➕ Add Hostel

## 🚀 Installation

### Clone Frontend

```bash
git clone https://github.com/Daji-Dudhal/Hostel_hunt_frontend.git
```

```bash
cd Hostel_hunt_frontend
```

```bash
npm install
```

```bash
npm start
```

---

### Backend

```bash
git clone https://github.com/Daji-Dudhal/hostelhunt_Backend.git
```

```bash
cd hostelhunt_Backend
```

Run the Spring Boot application.
